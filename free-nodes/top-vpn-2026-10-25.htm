一、为什么是Clash？—— 直播场景下的网络痛点与解法

在进入安装配置之前，我们有必要先厘清一个核心问题：为什么在众多代理软件（如SS、SSR、V2Ray等）中，Clash能脱颖而出，特别适合直播场景？

传统代理工具往往采用“全局代理”或简单的“PAC模式”，要么所有流量都走代理（导致国内网站访问变慢），要么规则死板难以应对动态变化的直播流。而Clash基于规则引擎（Rule-based Routing）的设计哲学，允许你精细化地定义：哪些IP段、哪些域名、哪些进程走代理，哪些直连。这意味着，你在开启代理的同时，依然可以享受本地网络的高速下载，同时确保直播流量精准地经由最优节点传输。

此外，Clash对多种协议的原生支持（Shadowsocks、VMess、Trojan、Snell等）意味着你无需为不同订阅源安装多个客户端，一个Clash即可统一管理所有节点。对于需要频繁切换线路以寻找最佳直播路线的用户来说，这种“一站式”体验堪称效率神器。

工欲善其事，必先利其器。Clash的安装过程并不复杂，但需根据你的操作系统选择对应的“口味”。

Windows用户：
访问Clash的官方GitHub Releases页面（搜索“Clash for Windows”或“Clash Verge”等图形化分支），下载最新的.exe安装包。推荐使用社区维护的“Clash Verge”或“Clash for Windows”，因为它们内置了图形界面和订阅管理功能，对新手极为友好。下载后双击运行，一路“Next”即可完成安装。安装完成后，桌面会出现一个猫咪或圆环图标，但此时它还无法工作——就像一把没装子弹的枪。

macOS用户：
类似地，在GitHub下载.dmg文件，拖拽至Applications文件夹。首次打开时，系统可能提示“已损坏，无法打开”，这是macOS的Gatekeeper机制在作祟。前往“系统偏好设置 -> 安全性与隐私”，点击“仍要打开”即可。

Linux/服务器用户：
对于追求极致性能或需要在远程服务器上部署代理的用户，可以使用命令行安装。通过wget下载对应架构的压缩包，解压后添加可执行权限，并在后台启动。虽然无图形界面，但核心功能完全一致。

关键一步：依赖检查
无论哪个平台，请确保你的系统时间准确（代理协议对时间偏差极其敏感），并安装了必要的根证书（部分分支版本会自动处理）。若启动时提示缺少.dll或.framework，请根据提示安装对应的运行库。

三、配置篇：从空白到“满血”的YAML魔法

Clash的灵魂在于其配置文件——一个以.yaml结尾的文本文件。对于普通用户，我们无需从零手写，只需掌握“导入”与“微调”两招。

第一步：获取订阅链接
你需要一个代理服务商提供的订阅地址（通常形如https://example.com/api/v1/client/subscribe?token=xxxx）。如果你还没有，可以选择购买商业机场服务，或者使用免费分享的节点集合（但稳定性与安全性需自行甄别）。复制这个链接。

第二步：导入配置
打开Clash图形界面，找到“配置”（Profiles）选项卡，将订阅链接粘贴到输入框中，点击“下载”。Clash会自动拉取远程配置文件并生成一个本地副本。点击该副本使其变为“激活”状态。

第三步：核心参数调整（直播特调）
此时，你可以点击“编辑”按钮，用记事本或VS Code打开YAML文件。对于直播场景，我们重点关注以下三个参数：

  1. mixed-port（混合端口）：这是HTTP和SOCKS5共用的端口，默认通常为7890。请记下这个数字，后续在直播软件中需要用到。
  2. allow-lan（局域网访问）：如果你打算使用手机或平板作为直播辅助设备（例如用手机摄像头推流），请将allow-lan: false改为true，并设置一个bind-address: 0.0.0.0。这样，同一Wi-Fi下的设备就能通过你的电脑IP和端口走代理了。
  3. rules（分流规则）：这是Clash的精髓。默认配置通常已包含“局域网直连”、“国内直连”等规则。对于直播，你无需大改，但可以确认是否有一条规则将直播平台（如twitch.tv、youtube.com）匹配到“PROXY”策略组。如果没有，你可以手动添加一条： ```yaml
    • DOMAIN-SUFFIX,twitch.tv,🚀 节点选择
    • DOMAIN-SUFFIX,youtube.com,🚀 节点选择 ``` 保存文件后，Clash会自动重载配置。

第四步：启动与验证
点击“系统代理”开关（或“设置为系统代理”按钮），让Clash接管系统流量。此时浏览器访问谷歌或YouTube，若能打开，则说明基础代理已生效。

四、实战篇：用Clash为你的直播“保驾护航”

配置完成后，我们正式进入直播实操环节。这里以最流行的开源直播软件OBS Studio为例。

场景一：国内平台直播（如B站、抖音）
这些平台服务器在国内，直连速度极佳。此时，你无需让直播流量走代理。在Clash中，由于默认规则包含“国内直连”，OBS推流到rtmp://live-push.bilivideo.com这样的地址会被自动识别为直连。你只需在OBS的“设置 -> 直播”中，选择“自定义流媒体服务器”，填入平台提供的RTMP地址和串流密钥即可。Clash在这里的作用是“隐身”，它静静地在后台保证你访问平台后台管理页面、上传封面图等操作流畅无阻。

场景二：海外平台直播（如Twitch、YouTube Live）
这是Clash发挥最大价值的场景。假设你想在Twitch开播，但网络直连丢包率高达30%。

  1. 选择节点：在Clash主界面，点击“代理”选项卡，在“节点选择”策略组中，手动切换至延迟最低、丢包率最低的节点（通常显示为绿色数字）。对于直播，建议选择“原生IP”节点，避免被平台风控。
  2. 获取RTMP地址：在Twitch的“创作者仪表盘”中，复制你的RTMP推流地址（如rtmp://live.twitch.tv/app）和串流密钥。
  3. OBS设置：在OBS中，选择“自定义”，填入上述地址和密钥。关键一步来了——OBS如何走Clash代理？
    • 方法A（最简单）： 如果Clash已开启“系统代理”，且OBS默认遵循系统代理设置（但部分版本OBS不读取系统代理），你需要在OBS中手动指定代理。但OBS原生不支持SOCKS5代理设置，此时我们需要借助工具。
    • 方法B（推荐）： 使用Clash的“TUN模式”（虚拟网卡模式）。在Clash Verge或CFW中，开启“TUN模式”或“虚拟网卡”。这会创建一个虚拟网卡，将所有系统流量（包括UDP、TCP）强制接管，无论OBS是否支持代理，其流量都会被Clash规则处理。开启TUN模式后，OBS无需任何额外设置，直接推流即可。

场景三：多平台同屏分发（如Restream）
如果你想要同时直播到多个平台，可以使用Restream这类聚合服务。此时，你的OBS只需推流到Restream的RTMP地址，Restream再分发到各平台。Clash需要确保与Restream服务器的连接稳定，同样开启TUN模式，并在规则中确保restream.io走代理。

直播中的网络监控
在直播过程中，你可以随时切换Clash的节点。如果发现画面卡顿，打开Clash主界面，观察当前节点的延迟和丢包率，一键切换到备用节点。这种“热切换”不会中断OBS进程，但可能会造成几秒钟的推流中断，建议在直播间隙操作。

五、常见问题与排雷指南

Q1：Clash开启后，OBS推流提示“连接超时”怎么办？
- 检查Clash是否开启了TUN模式（或系统代理是否包含UDP转发）。RTMP协议基于TCP，但直播平台的域名解析需要DNS。请在Clash的DNS设置中，确保使用了如https://dns.google/dns-query或https://1.1.1.1/dns-query等远程DNS，避免DNS泄漏导致连接失败。 - 尝试在Clash中临时将直播域名的规则改为“DIRECT”（直连），排除代理节点本身故障。

Q2：Clash能否提高直播画质？
不能。Clash只负责网络传输路径的优化，不改变视频编码。但如果你的网络丢包严重，Clash通过切换到优质节点，可以减少数据重传，从而减少画面马赛克和音画不同步，间接提升观看体验。

Q3：使用Clash直播是否会被封号？
这是一个灰色地带。对于海外平台，使用代理属于违反其“服务条款”的行为，存在极小概率的风控封号风险。建议使用原生IP节点，并避免在直播中展示敏感信息。对于国内平台，Clash仅用于加速后台管理，不影响推流，风险极低。

Q4：Clash配置更新后，我的自定义规则丢失了？
这是正常现象。远程订阅更新会覆盖本地文件。如果你有必须保留的规则，可以在Clash的“配置”选项卡中，使用“局部覆盖”或“脚本”功能（如JavaScript覆写），将自定义规则写入main函数中，这样每次更新后脚本会自动合并。

Q5：直播时CPU占用率过高，Clash是否拖累了性能？
Clash基于Go语言编写，内存和CPU占用极低（通常在50MB以内）。若发现占用高，可能是开启了TUN模式后，系统网卡驱动与虚拟网卡冲突。尝试关闭TUN模式，改用“系统代理”+OBS的“环境变量”方式（在OBS快捷方式目标中追加--proxy-server="http://127.0.0.1:7890"）来强制OBS走代理。

如何用 iptables 限制 V2Ray 服务的访问来源？
使用 iptables 规则仅允许可信 IP 或 CDN 的中转 IP 访问服务端口，例如 `iptables -A INPUT -p tcp -s --dport 443 -j ACCEPT`，并在默认策略下拒绝其他来源，从而降低被扫描与滥用风险。
Mellow TUN 模式如何拦截全局流量？
TUN 模式会拦截系统 IP 层的所有流量，实现全局代理。相比 SOCKS5 只影响部分应用，TUN 可以覆盖游戏、视频和浏览器等所有流量，提高科学上网体验的全面性。
Mellow 如何配置透明代理？
Mellow 的透明代理功能可通过 TUN 模式或 WinDivert 实现。启用后系统流量会自动通过代理转发，无需手动设置浏览器代理，适合全局科学上网场景。
Shadowrocket 的节点测速结果如何应用？
节点测速结果可用于策略组选择和自动切换，程序会根据延迟和丢包率选择最优节点。这样访问海外网站或流媒体时，可以保持高速和稳定的网络体验。
PassWall2 支持哪些内核？
PassWall2 支持多种代理内核，如 Xray、V2Ray、Sing-box、Trojan-go、Hysteria2 等。用户可在插件管理中切换所需内核，以获得不同协议与性能的支持。部分内核需手动下载并启用。
